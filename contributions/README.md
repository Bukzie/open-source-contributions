# Contributions

Records of work that has actually started or finished. This folder is **empty by design** on 2026-11-05: no
implementation has begun on any candidate.

- `in-progress/`: one file per active contribution, created only after owner approval to IMPLEMENT
- `completed/`: one file per merged or closed contribution, with the PR link and final outcome

Each record should hold: upstream link, implementation SHA, reproduction evidence, test commands and results,
AI-assistance disclosure as submitted, review notes, and the final outcome.
